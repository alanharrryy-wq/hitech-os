# Panel Locator

Read-only interface map generator. It scans surfaces, CSS modules, selectors, pseudo layers, visual risks, duplicate selectors, token usage, and component ownership. It does not modify UI and does not generate agent-specific prompts.

Run:

```bash
node tools/quality/panel-locator.mjs --surface tablet-pos --out-dir F:/descargasf/panel-locator-result
```
