# 73_SMOKE_CHECKS_AND_EVIDENCE

## Smoke checks

- canonical docs present
- staging root present
- mutation client entrypoints present
- mutation integration entrypoints present
- no direct preview-equals-commit wording in new docs
- bridge boundary docs still present

## Evidence discipline

Each run should create:

- machine-readable JSON report
- human-readable TXT report
- stdout/stderr captures where external tooling runs
- next commands that the operator can paste immediately
