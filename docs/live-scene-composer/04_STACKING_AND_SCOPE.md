# Stacking and scope

This bundle assumes the repo already validated the mutation integration hardening wave.

## In scope
- end-to-end UI action routing contracts
- preview / commit controller wiring
- compare/apply bar state model
- keyboard and toolbar bindings for commit/discard/reset
- evidence and smoke checks for staged seams

## Out of scope
- direct runtime implementation details
- replacing the bridge
- flattening Scene / Layout / Slots / Widgets into UI-only notions
- absorbing authoring logic into runtime-debug-console
