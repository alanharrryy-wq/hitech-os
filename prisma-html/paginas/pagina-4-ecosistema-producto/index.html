ECOSISTEMA DEL PRODUCTO

Un núcleo operativo. La superficie correcta para cada persona.

Tablet opera. PC gobierna. Mobile supervisa. Chart Lab explica. Control Center administra la plataforma. Web abre la puerta. Ninguna superficie posee la verdad: todas la proyectan desde el mismo núcleo.

SEIS SUPERFICIES, SEIS RESPONSABILIDADES

No son versiones pequeñas o grandes de la misma pantalla.

Cada superficie existe para un rol y un momento operacional. Selecciona una para ver qué hace, qué información consume, qué evidencia presenta y qué resultado debe producir.

UNA VENTA, TODO EL ECOSISTEMA

La acción ocurre una vez. El valor aparece donde corresponde.

Recorre las capas. El objetivo no es copiar la misma pantalla en todas partes, sino conservar significado y producir una representación útil para cada superficie.

CAPA 01 · SCOPE

Antes de contar la venta, PRISMA sabe a quién y a dónde pertenece.

Tenant, negocio, tienda, terminal, dispositivo, usuario, rol, licencia y sesión forman el contexto mínimo.

CAPACIDADES, NO APLICACIONES ENJAULADAS

Los módulos se habilitan sobre el núcleo y se proyectan donde aportan valor.

Una capacidad puede aparecer en varias superficies sin duplicar su significado. La licencia y el rol determinan qué se puede hacer; el contexto determina cómo debe mostrarse.
