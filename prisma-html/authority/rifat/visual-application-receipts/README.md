# GVAE application receipts

This directory contains deterministic, transaction-bound receipts emitted by successful non-idempotent GVAE `APPLY` operations.

Rules:

- receipts are generated by GVAE, not hand-authored;
- each receipt is bound to one exact Target Index target and one GVAE transaction;
- receipt file transitions carry before/after SHA-256 values used by the mandatory CI gate;
- receipts carry source/static authority summaries only;
- receipts do not prove runtime/browser visuals, production readiness, or whole-surface coverage;
- rollback restores/removes the receipt together with the transaction it describes.

A registered GVAE target source or generated projection cannot be changed in a mergeable PR without a valid receipt chain from the PR base bytes to the PR head bytes.
