# PRISMA HTML · Layers Map Clear Pearl

| Layer | Responsibility | Canonical owner |
|---|---|---|
| L0 | Pearl atmospheric field with governed Aurora/Liquid assets beneath a high-key veil | `narrative-page.css` |
| L1 | Cold-blue illumination, halo and optical depth | `narrative-page.css` |
| L2 | Clear Pearl Glass surface, border, blur and refraction | `tema-base.css` + `narrative-page.css` |
| L3 | Graphite typography, official logo and operational content | page HTML + shared tokens |
| L4 | Selected tab, step, button, focus and interaction feedback | shared components |

## Hard rules

- Five visible layers maximum.
- Dark assets never define the public page base color.
- Alpha `0` produces a transparent material surface.
- No `!important`.
- No page-level authority contradicts the shared Clear Pearl system.
- Visual validation was not run by user request.
