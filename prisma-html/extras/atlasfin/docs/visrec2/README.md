# VISREC2 V2

VISREC2 es una consola source-only para crear recetas visuales portátiles completas.
Mantiene exactamente los controles visibles de V1 y resuelve la complejidad nueva
mediante registries, presets, recetas, reglas, adaptadores y valores predeterminados.

No aplica CSS a Tablet, PC, Mobile ni otras superficies. Los contratos JSON enlazan
VISREC2 con IDDICT, IDEXPORT, IDBIND, IDLAYER, IDRECIPE e IDAPPLY.
