# Adapters

Los adapters documentan integracion con implementacion viva. No crean un
segundo sistema.

- `cloud-center-adapter.md`: extiende Prisma Cloud Ctr/3160.
- `tablet-surface-adapter.md`: emite SurfaceStatus desde la licencia Tablet.
- `pc-surface-adapter.md`: emite SurfaceStatus desde la licencia PC.
- `mobile-surface-adapter.md`: expone Mobile License & Devices.
