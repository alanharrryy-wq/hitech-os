## Regla de lectura rápida

PRISMA debe entenderse como una **plataforma POS modular**, no como un POS simple.

La narrativa central es:

> PRISMA convierte el punto de venta en centro de mando comercial: vende, controla, sincroniza y crece por core, módulos y plugins.

La narrativa visual aprobada es:

> **Una plataforma modular. Dos experiencias visuales: PRISMA Black y PRISMA Light.**

La narrativa técnica de datos es:

> **Prisma ORM ayuda a que PRISMA tenga una base de datos ordenada, trazable y lista para crecer por módulos y plugins.**
