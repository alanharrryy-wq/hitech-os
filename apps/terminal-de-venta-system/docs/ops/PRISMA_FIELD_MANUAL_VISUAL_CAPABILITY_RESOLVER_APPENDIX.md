# PRISMA Field Manual Appendix: Visual Capability Resolver

## Learning

Before any visual/premium change, the Authority Mesh must not only resolve documents/government sources. It must also resolve available visual capabilities by app/surface.

## Mandatory files

For visual or premium work, `.governance/current` must include:

- `VISUAL_CAPABILITY_MATRIX.json`
- `VISUAL_CAPABILITY_MATRIX.md`
- `VISUAL_STACK_DECISION.md`
- `APP_VISUAL_EXPLOITATION_MATRIX.md`

## Rule

Available libraries and visual systems must be exploited when useful, governed, performant, and surface-compatible. If not used, the result must explain why.

Do not ask agents to use every library blindly. Ask them to use the maximum safe, governed visual stack for the target app/surface.

## No fake green

A functional smoke test does not validate visual premium quality. Visual evidence is required or must be marked pending.
