## Maintenance rule

When a governed operator workflow materially changes:

- update its canonical runbook and this index in the same documentation closure where practical;
- add the operational learning to the Field Manual;
- update the Factory Ledger or Evidence Index only when capability/evidence truth actually changes;
- preserve historical exception and closeout records instead of rewriting history;
- never make documentation claim a maturity state that the current evidence does not prove.
