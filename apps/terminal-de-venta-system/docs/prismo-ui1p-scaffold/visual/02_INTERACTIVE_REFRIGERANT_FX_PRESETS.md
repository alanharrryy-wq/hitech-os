# Interactive Refrigerant FX Presets

## Design promise
Coolant-green crystal, premium graphite depth, semantic glow, hydro rims, and low-opacity glass.

## Anti-opacity commandments
1. Surface fill stays below route budget.
2. Text is never placed on distorted glass.
3. Blur supports depth; it does not replace contrast.
4. Strong glow appears once per viewport.
5. Drawer can be rich but content planes stay readable.
6. If glass looks milky, lower fill/blur and refine border/highlight.
