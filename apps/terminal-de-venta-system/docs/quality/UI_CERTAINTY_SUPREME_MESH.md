# PRISMA UI Certainty Supreme Mesh

This layer turns UI evidence into enforceable contracts.

Core rule:

```text
Sin CERTIFIED, no se toca.
Con CERTIFIED, sólo se toca lo permitido.
Si hay DRIFT o CONFLICT, se arregla ownership antes del visual.
```

The system combines:

- Authority Mesh
- posctx / surface context
- Mamastrophic point-probe runtime evidence
- Layer Map
- ops/manual rules
- panel contracts and anchors
- scope guard
- zero-important gate
- visual evidence gate

Initial contracts are seeds for all known PRISMA ports/surfaces. They are not a fake green.


## all4 worker/shard guarantee

This package propagates `-Workers` and `-Shards` into every Mamastrophic child point-probe and writes `reports/worker_shard_audit.json`. If any child runtime reports a mismatch, the run is FAIL.
