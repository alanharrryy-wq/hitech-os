# PRISMA black-box runtime doctor 05A

Local Python doctor for status, last-error, reports, evidence collection and safe repairs.

# Acceptance

Installer: --run only, --rollback only, manifest/checksums, backup, apply, verify, functional smoke, rollback on failure.

# Runbook

Use status, doctor --allow-blocked, last-error --allow-blocked, collect --allow-blocked, repair plan, repair apply --safe.
