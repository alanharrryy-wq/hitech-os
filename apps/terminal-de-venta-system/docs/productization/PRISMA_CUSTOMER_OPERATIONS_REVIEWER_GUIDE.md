# PRISMA Customer Operations Reviewer Guide

## Propósito

Guía para revisar futuras entregas antes de aplicar cambios sobre licencias, soporte, mensajes, anuncios, plugins, updates e IA futura.

## Revisión 1

Preguntas obligatorias:

1. ¿La entrega mantiene Tablet standalone?
2. ¿La entrega evita dependencia dura de Remote Ops?
3. ¿La entrega tiene dry-run, apply, verify y rollback?
4. ¿La entrega deja backup si reemplaza archivos?
5. ¿La entrega evita pagos bancarios internos?
6. ¿La entrega respeta roles y permisos?
7. ¿La entrega evita popups comerciales en checkout?
8. ¿La entrega evita comandos remotos arbitrarios?
9. ¿La entrega valida JSON, manifests o contratos nuevos?
10. ¿La entrega deja log único?

Respuesta esperada: ready, ready-with-notes o blocked. Si algo huele a parche mágico, se bloquea. Los parches mágicos son como cinta canela en fuga de gas: emocionantes, pero por razones equivocadas.
