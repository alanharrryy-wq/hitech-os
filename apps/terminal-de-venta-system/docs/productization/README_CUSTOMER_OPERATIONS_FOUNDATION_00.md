# PRISMA Customer Operations Foundation 00

## Qué instala este paquete

- Contratos Markdown para Customer Operations Layer.
- Schemas JSON para licencia, entitlements, messaging, announcements, soporte, plugins, remote commands, diagnostics y releases.
- Manifest del paquete.
- Plan de instalador.

## Qué no instala

- Remote Ops real.
- Local Agent real.
- UI de Centro PRISMA.
- Plugins reales.
- IA real.
- Procesamiento de pagos bancarios.
- Cambios en Tablet o PC runtime.

## Uso previsto

Este paquete es la base para que futuras entregas implementen licencias, soporte, mensajes, novedades, plugins, updates e IA futura con contratos claros.
