
# Definition of Done

A PRISMA Visual System change is DONE only when:

- scope is explicit;
- touched files are within allowlist;
- no-touch surfaces are enforced;
- registries validate against schemas;
- component statuses are truthful;
- adapters define runtime background, density, interaction, and QA constraints;
- forbidden patterns are scanned;
- result/fail ZIP is generated;
- continuation is written;
- visual evidence is captured when a server is already available, or explicitly skipped with reason.

Compilation alone is not visual success. JSON parsing alone is not system success.
