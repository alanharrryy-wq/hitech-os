## Intencion

No modifica UI ni runtime. Es una fuente de datos minima y verificable para que el siguiente atomic pueda hidratar pantallas sin inventar datos sueltos en cada componente.

## Regla

Estos seeds son chicos a proposito. Queremos datos suficientes para validar productos, tickets, inventario bajo, stockout, KPIs y resumen movil.

Si un seed empieza a parecer novela rusa, ya se salio del carril.
