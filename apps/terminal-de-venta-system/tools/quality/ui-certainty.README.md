# PRISMA UI Certainty Supreme Mesh

Repo-native gate for panel contracts, anchors, CSS selector ownership, scope guard and zero-important visibility. This tool is intentionally strict: seed contracts are not CERTIFIED until local anchors and selectors validate.

Commands:

```powershell
pnpm run ui:certainty:self-test
pnpm run ui:certify -- --surface all
pnpm run ui:scope
pnpm run ui:work -- --panel tablet.pos.checkout-diagnostic
pnpm run ui:zero-important
```
