# Industrial CRS Rectifier Scenario

The Industrial CRS scenario exists to prove PRISMA is not just a POS.

A complete CRS rectifier flow should eventually demonstrate:

- asset
- site
- rectifier
- measurement/reading
- technician/responsible
- alert
- status
- evidence
- timeline/audit trail

Phase 3 may warn if this is partial. It must never pretend the CRS vertical is complete without evidence.
