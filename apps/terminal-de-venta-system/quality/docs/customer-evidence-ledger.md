# Customer Evidence Ledger

Customer evidence is the audit trail that makes a readiness claim defensible.

Files of interest:

- `QUALITY_EVIDENCE_LEDGER.jsonl`: raw gate evidence entries.
- `CUSTOMER_EVIDENCE_LEDGER.json`: customer-facing summary of gate status and evidence count.
- `CUSTOMER_ASSURANCE_SNAPSHOT.json`: critical file fingerprint baseline.
- `CUSTOMER_SUPPORT_PACK_MANIFEST.json`: support export contract.

No green claim is accepted without parseable JSON evidence.
