# PRISMA Tablet Atmospheric Backgrounds v4

Agrega cuatro fondos a `/visual-os/tablet-background-gallery`:

1. `Tablet Soft Gray Clouds` como candidato light/default.
2. `Obsidian Cloud Motion` como dark showcase.
3. `Storm Glass Horizon` como dark showcase.
4. `Aurora Slate Veil` como dark showcase.

Los fondos oscuros existen sólo como exploración visual de galería. No se aplican a Tablet productiva ni a `/pos`.

La ruta ya lee primero `docs/design/tablet-light-visual-preset-engine`, por eso estos assets quedan vivos: si se actualiza HTML/CSS/JS/JSON en esa carpeta, la galería refleja el cambio sin modificar la ruta.
