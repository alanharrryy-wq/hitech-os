# PRISMA Tablet Codex Background Gallery

Demo scrolleable y con selector de backgrounds codex-native para Tablet Light.

## Qué corrige

El demo anterior enseñaba muchos paneles, pero el background no era el protagonista.
Este paquete convierte el background en laboratorio visual real.

## Incluye

- 10 backgrounds claros.
- Selector lateral sticky.
- Paneles glass encima para probar legibilidad real.
- Modo lluvia sutil.
- Backgrounds con IDs del códex/adapters.
- Motion ambiental.
- Reduced-motion.
- React shell futuro.
