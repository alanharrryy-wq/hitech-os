# PRISMA Tablet Codex Native Glass Gallery Demo

Este paquete crea un demo scrolleable, claro y codex-native para revisar muchos paneles/presets del códex en Tablet Light.

## Qué incluye

- Galería scrolleable con más de 30 paneles.
- Grupos: background, glass, rim, glow, motion, bundles, bibliotecas y physical/G5.
- Filtros laterales y búsqueda.
- Detalle tipo drawer/overlay.
- Toast visual.
- Motion demo.
- Hover tilt y scroll reveal.
- `prefers-reduced-motion` respetado.
- Mapping JSON con IDs reales del códex.
- React shell futuro: `TabletCodexGlassGalleryDemo.tsx`.

## Regla visual

El demo adapta presets del códex a Tablet claro. Algunos presets originales son oscuros o de PC; aquí se muestran como versión `tablet-light-adapter`.
