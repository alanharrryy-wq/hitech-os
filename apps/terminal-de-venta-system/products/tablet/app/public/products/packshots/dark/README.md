# PRISMA Tablet Dark packshots

Drop Dark/Black-skin PNG packshots here.

Filename contract:

```text
brand-product-variant-size.png
```

Example:

```text
aurevia-pan-de-caja-multigrano-620g.png
```

Served by Next.js as:

```text
/products/packshots/dark/aurevia-pan-de-caja-multigrano-620g.png
```
