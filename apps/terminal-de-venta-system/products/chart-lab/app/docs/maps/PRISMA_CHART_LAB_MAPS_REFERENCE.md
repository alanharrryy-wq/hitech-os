# PRISMA Chart Lab Maps Reference

Machine-readable maps live in `src/prisma-charts/maps/chart-lab-maps.ts`.

Human-readable index:

- Atlas: what exists and where it renders.
- Sources: what is safe, partial, unavailable, or unsafe.
- Controls: which runtime knobs affect data/options.
- Knobs: premium ranges, risk, accessibility, performance.
- Recipes: family defaults and surface overrides.
- States: happy, empty, partial, stale, offline, unknown, dense, critical.
- Intent: human phrases to chart/edit files/validation.
- Transport: valid targets and unsafe targets.
- Promotion: source, target, flags, backups, rollback.
- Routes: local, product preview, production, Pages, Tunnel.
- Dependencies: allowed and forbidden imports.
- Cloudflare: exposure mode and denied diagnostics.
- Validation: verifier command map.
- Handoff ZIP: future context pack contents.
