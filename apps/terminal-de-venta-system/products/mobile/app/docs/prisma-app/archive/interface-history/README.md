# PRISMA Mobile interface history archive

This directory preserves byte-exact historical interface/product documents that were retired by `PRISMA_MOBILE_INTERFACE_CANON.md`.

Rules:

- Files here are **historical evidence**, not current product-interface authority.
- Compatibility paths remain as tombstones when existing verifiers or documentation may still reference the old filename.
- Do not re-mount UI or restore navigation from an archived document without a new governed Mobile interface change.
- Technical APIs, builders, components, QA corpora and verifiers are preserved separately and are not deleted by this documentation-only consolidation.
