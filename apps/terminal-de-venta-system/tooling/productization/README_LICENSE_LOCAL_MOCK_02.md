# PRISMA License Local Mock 02

Esta carpeta contiene contratos, schemas y ejemplos para la futura lectura local de licencias.

No contiene secretos.
No contiene licencias reales.
No procesa pagos.
No implementa Remote Ops real.
No debe ser usado para bloquear ventas hasta que exista implementacion y pruebas.

## Carpetas

- `schemas`: contratos JSON.
- `examples/license-local`: licencias mock y catalogo de planes.
- `test-cases`: casos esperados para resolver features.
- `playbooks`: guias de operacion.
- `manifests`: manifest del paquete.
- `installer-plan`: plan de instalacion.
