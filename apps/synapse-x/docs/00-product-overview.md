# Product Overview

## What is SYNAPSE-X
SYNAPSE-X is a local operational memory engine that ingests sessions, logs and reports, then turns them into searchable, structured knowledge.

## Problem
Operational data is fragmented across sessions, logs and reports. It is hard to query, correlate and learn from that data.

## Outcome
A local-first system that can:
- ingest incrementally
- normalize heterogeneous sources
- persist structured entities
- expose search and metrics
- reconstruct timelines
- surface frequent failures and patterns

## Users
- local operator
- developer
- incident reviewer
- analyst

## Scope v1
- local ingestion
- SQLite
- cache and raw store
- FTS-based search
- local UI
- repair and watch operations
