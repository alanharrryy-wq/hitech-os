# Capatch Output Policy

The repository must remain source-clean. Operational evidence belongs outside the repo.

## Rule

A real mutation must create a run bundle under `F:\descargasf` by default.

## Bundle contents

- `manifest.json` and `manifest.md`
- logs
- reports
- backups before changes
- current/final file snapshots
- rollback manifest
- continuation notes when applicable

## Forbidden repo residue

- `.capatch/` runtime folders
- generated `reports/`
- plugin `_logs/`
- dependency graphs generated by one-off analysis
- ChatGPT scratch backups
- patch attempt temporaries
