# Capatch Surgical Upgrade

This upgrade introduces a cleaner operating model:

1. keep Capatch source clean;
2. export all runtime evidence outside the repo;
3. load behavior through cartridges;
4. preserve multi-file patching;
5. harden visual and surface-aware workflows;
6. include rollback evidence in every mutation bundle.

## Result

Capatch becomes a reusable surgical console instead of a folder that collects logs, backups and fossils.
