# Foundry Studio Suite

This document describes the third heavy injection layer for `pyside6_glass`.

It exists to make recipe authoring, inspection, export and audit feel boringly reliable.
That is a compliment.

## What it adds
- a main-window based studio shell with dockable doctor and cookbook panels
- a variant inspector for recipe, beauty, color, motion, layout, shell and interaction selection
- an outline pane so complex payloads stay inspectable instead of mystical
- a registry pane to verify what the platform actually knows right now
- JSON export suitable for compiler, diff and patch workflows
- undo/redo for selection changes through Qt's undo framework
- optional file watching hooks for future live-manifest loops

## Why it matters
The first two injections make the platform safe and composable.
This third one makes it usable by tired humans on real deadlines.

## Guardrails
- variants are data first, preview second
- preview swaps owned stage children instead of piling widgets into a haunted mansion
- the doctor reports missing contracts before runtime drama appears
- cookbook guidance lives next to the preview instead of in a forgotten markdown tomb
- export stays pure JSON so other tools can consume it

## Reference Notes
## Studio Pattern 1
- Goal: make authoring gorgeous interfaces feel deterministic instead of artisanal chaos.
- Rule: the studio edits variants, not live widget internals.
- Rule: preview rebuilds must swap owned stage children, never stack fresh shells over old ones.
- Rule: every recipe variant must declare beauty profile, color story, motion profile, density and interaction profile.
- Rule: the doctor should flag missing empty/loading/error states, risky overlays and questionable hit targets before shipping.
- Rule: export is pure JSON so future compilers, differs and code generators can consume it without GUI baggage.
- Pattern: one preview stage, one outline, one inspector, one cookbook, one doctor, all cooperating like a pit crew.
- Commentary: if a design studio starts behaving like a haunted house, it means the ownership model got sloppy long before the gradients looked sexy.
