
# Foundry Interaction Safety

Version: `foundry.interaction_safety.v1`

This layer exists to stop premium interfaces from becoming haunted houses.

## What it adds
- overlay portal with pass-through décor and deliberate blocking sheets
- page host built around a single visible page at a time
- focus circuit for explicit tab travel
- shortcut router with page/mode awareness
- safety auditor for tiny hit targets, interactive pass-through mistakes and risky splitter settings
- catalog entries for interaction patterns

## Reference notes
## Safety Pattern 1
- Goal: Keep interaction predictable even when visual ornament gets rich.
- Rule: Decorative layers must be pass-through by default.
- Rule: Navigation containers own page lifetime; pages do not raise themselves above siblings.
- Rule: Focus order is declared or synthesized from geometry, never left to luck in dense workspaces.
- Rule: Splitters restore safely and clamp invalid ratios before users see broken geometry.
- Rule: Every modal surface publishes an exit action, Escape shortcut, and visible close affordance.
- Rule: Audit output must explain not only that something failed, but why it is risky to users.
- Commentary: In a recipe-driven UI platform, beauty should be a passenger riding on rails, not a drunk unicycle rolling through the input stack.
