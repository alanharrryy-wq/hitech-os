# Code Atlas Dependency Visual V04.1

V04.1 is a standalone offline HTML command deck for Code Atlas dependency graphs.

## Purpose

It consumes the graph and summary generated by Code Atlas Dependency Consumer V03.1 and renders a richer visual interface with:

- animated dependency field
- runtime focus mode
- workspace filtering
- node kind filtering
- edge class filtering
- degree threshold filtering
- standard-library hiding
- unresolved-only mode
- selected-node neighborhood mode
- top external imports
- unresolved imports table
- filtered graph JSON export

## Non-goals

- Does not scan source code.
- Does not modify Capatch.
- Does not modify `code-atlas.py`.
- Does not write anywhere except the requested output directory.
- Does not fetch network assets.

## Commands

Render:

```powershell
python "F:\repos\hitech-os\apps\code-atlas\tools\code_atlas_dependency_visual_v04_1.py" render --graph-json "F:\descargasf\code_atlas_dependency_consumer_v03_terminal-de-venta-system_260504_2150_graph.json" --summary-json "F:\descargasf\code_atlas_dependency_consumer_v03_terminal-de-venta-system_260504_2150_summary.json" --output-dir "F:\descargasf" --title "Terminal de Venta Dependency Command Deck"
```

Verify:

```powershell
python "F:\repos\hitech-os\apps\code-atlas\tools\code_atlas_dependency_visual_v04_1.py" verify --graph-json "F:\descargasf\code_atlas_dependency_consumer_v03_terminal-de-venta-system_260504_2150_graph.json" --summary-json "F:\descargasf\code_atlas_dependency_consumer_v03_terminal-de-venta-system_260504_2150_summary.json" --max-unresolved 3 --forbid-source-prefix tools/prisma-salvage --expect-graph-version 3.1.0
```

## Expected verification

The verifier should return `ok: true` with graph version `3.1.0`, no salvage edges, no empty external node, and no stdlib imports classified as file nodes.

## Rollback

