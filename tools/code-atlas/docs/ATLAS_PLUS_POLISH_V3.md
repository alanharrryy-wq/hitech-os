# Atlas Plus Polish V3

This iteration tightens Todo El Show Plus around two rules:

1. **META auto-discovery**: Atlas Coverage Audit now searches explicit CLI paths, environment roots, the selected project, `_dependency_graphs`, `evidence`, `F:\PRISMA_CTX`, `F:\PRISMA_CTX\00_ALL\ALV`, and top-level `F:\descargasf` for atlas/meta evidence. ZIP META files such as `TodoALV META.zip` are parsed directly without extracting the entire archive.
2. **Single ZIP discipline**: the inner `todo el show plus ... bundle.zip` is disabled. The PySide6 Todo El Show Plus button leaves one final ZIP in downloads and places all reports inside it.

The manifest is only the receipt/map of what was executed and captured. It is not a runtime dependency.
