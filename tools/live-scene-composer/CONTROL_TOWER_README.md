# Live Scene Composer Control Tower

Este archivo fue generado para dejar una sola entrada operativa en Python.

## Entrypoint principal
- `control_tower.py`

## Qué hace
- inventario real del filesystem
- generación de artifacts de arquitectura
- ejecución del guard documental/arquitectónico
- escritura de evidencia en `_local/evidence`

## Comandos
- `python tools/live-scene-composer/control_tower.py --repo-root . inventory-real`
- `python tools/live-scene-composer/control_tower.py --repo-root . artifacts`
- `python tools/live-scene-composer/control_tower.py --repo-root . guard`
- `python tools/live-scene-composer/control_tower.py --repo-root . full`
