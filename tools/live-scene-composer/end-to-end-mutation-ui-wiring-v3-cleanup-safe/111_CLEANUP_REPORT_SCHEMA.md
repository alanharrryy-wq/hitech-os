# 111_CLEANUP_REPORT_SCHEMA

Cleanup report fields:
- package
- mode
- repo_root
- docs_root
- staging_root
- summary_dir
- removed_legacy_staging_roots
- removed_legacy_docs
- removed_v3_staging_root
- removed_v3_canonical_docs
- warnings
- verification_after_cleanup

The report exists so the operator can see what was actually deleted.
