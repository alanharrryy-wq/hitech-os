# Review Model

## Review types

### Constitutional review
Checks:
- authority boundaries
- source precedence
- package topology and dependency logic
- change budget correctness
- prompt usage compliance

Owner:
- governance chat
- operator when constitutional changes are large

### Homologation review
Checks:
- project baseline completeness
- path ownership plausibility
- run objective clarity
- package fit

### Package freeze review
Checks:
- package scope and non-goals
- dependencies and consumers
- acceptance gates
- handoff format
- unresolved upstream assumptions

### Bundle review
Checks:
- schema and structure validity
- ownership compliance
- payload integrity
- overlap with other packages
- coherence between report and payload

### Integration review
Checks:
- dependency order
- conditions on accepted packages
- residual risk
- downstream consumer notifications

### Closeout review
Checks:
- decisions recorded
- run objective status
- remaining debt or open risk
- readiness for the next round or run

## Review outputs
Every review produces:
- pass, pass with conditions, or fail
- reasons
- required follow-up actions
- references to the artifacts reviewed
