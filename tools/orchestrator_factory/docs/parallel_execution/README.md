
# Parallel Execution Tactical Subsystem

This subsystem provides the **factory-floor mechanics** for governed parallel work.

## Subordinate authority
This subsystem is tactical, not constitutional. If any tactical artifact conflicts with `00-governance-core/`, the tactical artifact loses.

## What it handles
- project baseline bootstrap support
- run and round packet generation
- work packet structure
- deterministic bundles
- validation
- overlap detection
- acceptance reporting
- retry loops
- readiness checking
- integration readiness summaries
- prompt choreography
- pilot run support

## What it does not handle
- package topology authority
- canonical term approval
- source precedence
- constitutional changes

Those remain governance responsibilities.
