# Tactical Naming Conventions

- run IDs: `run-prj-<slug>-<YYYYMMDD>-<NN>`
- round IDs: `rd-<NNN>`
- bundle IDs: `<run_id>__<round_id>__<package_id>__v<NN>`
- run folders: `ops/runs/<run_id>/`
- round folders: `ops/runs/<run_id>/rounds/<round_id>/`
- incoming bundles: `ops/runs/<run_id>/rounds/<round_id>/incoming/`
- reports: `ops/runs/<run_id>/rounds/<round_id>/reports/`
