# Operator Handoff

## Installing the subsystem
- copy the framework into the repo root or into the documentation root used by the project
- keep relative paths intact
- do not scatter copies of schemas, prompts, or tools in random folders

## Running it safely
- edit path policies during homologation
- initialize the run before generating round artifacts
- validate before integrating
- record decisions when freezing changes

## What not to do
- do not bypass acceptance reports
- do not patch bundle conflicts manually without a record
- do not let package chats invent ownership on the fly
