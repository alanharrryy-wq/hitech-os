
# Integration Readiness

## Integration-ready means
- accepted packages are known
- rejected packages are known
- apply order is known
- conditions on accepted packages are visible
- residual risks are stated
- any active waiver is visible
- contract-version alignment is visible where it matters

## Inputs to the readiness decision
- acceptance report
- overlap report
- validated bundles
- dependency graph
- decision records that modified the active baseline
- waiver records that authorized exceptions

## Output
Mission control should produce:
- integration status
- suggested apply order
- remaining blockers
- exact follow-up actions if not ready
- conditions and waiver references if proceeding with controlled exceptions
