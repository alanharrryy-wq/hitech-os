# Prompt Choreography

## Sequence
1. freeze governance and project baseline
2. initialize run and round
3. generate work packets
4. generate worker prompts from the generic template plus each packet
5. collect bundles
6. generate retry prompts only from the acceptance report

## Why this matters
Prompt choreography keeps prompts derivative. The prompt becomes the latest operational wrapper around the real contract surface instead of a parallel shadow constitution.

## Hard rule
Never hand a worker only a prompt when the work also depends on frozen docs or a work packet.
