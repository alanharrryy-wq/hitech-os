
# Tactical Operating Model

## Rule of gold
Nothing is integrated because a worker described it well. It is integrated because the bundle, the report, and the acceptance decision say it is safe.

## Working assumptions
- package chats do not edit each other directly
- workers do not communicate directly with each other
- mission control trusts manifests and validation more than narration
- ownership is enforced at path level
- bundle versioning matters
- retries are package-scoped, not free-for-all rewrites
- exceptions require written waivers, not verbal permission

## Default mode
The governance chat acts as mission control. This matches the target 1 governance + 6 package model and avoids introducing an unnecessary eighth chat.

## Optional split mode
For especially large or audited efforts, mission control may be delegated to a separate chat. The constitution still outranks it.
