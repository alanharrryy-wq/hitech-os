# Chat Operator Playbook

## Default chat map
- Chat 0: governance and mission control
- Chats 1-6: package chats

## Discipline rules
- do not paste files manually between chats as if that were governance
- always route shared changes through constitutional docs or run-control artifacts
- always use work packets and bundle validation for parallel rounds
- always keep package scope narrower than temptation

## When to pause instead of pushing ahead
- package topology unclear
- runtime ownership unclear
- canonical source conflict detected
- acceptance report says reject
