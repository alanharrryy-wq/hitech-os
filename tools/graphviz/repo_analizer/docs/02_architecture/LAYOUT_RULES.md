# Convención de layout

## Raíz mínima
La raíz del proyecto debe contener solamente el archivo que arranca la herramienta.

## Distribución
- `main.py` arranca GUI o CLI.
- Todo el resto vive dentro de carpetas con responsabilidad clara.

## Ventaja
Cuando abras el folder en Windows Explorer o VS Code, no verás un tiradero de `.py` mezclados con docs.
